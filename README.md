# Codex 字幕翻译台

本地日文 SRT 转简体中文字幕工具。网页只负责选择文件和下载结果，翻译由当前电脑上已经登录的 Codex CLI 完成，不需要额外填写 OpenAI API Key。

## 使用

双击 `start.cmd`，浏览器会打开：

`http://127.0.0.1:4317`

然后：

1. 拖入日文 `.srt` 文件。
2. 选择智能断句或严格时间轴。
3. 选择纯中文字幕、日中双语，或同时生成两份。
4. 点击“调用 Codex 翻译”。
5. 校验通过后下载字幕。

上传的字幕会先经过预检。零时长字幕会在内存中自动补时长；同一时刻、相同文本的连续零时长字幕会合并并重新编号。发生修复时，结果区会额外提供一份 `*.repaired.ja.srt`，原文件始终保持不变。结束时间早于开始时间或无法安全推断的时间冲突不会被强行修改，程序会明确报错。

## 两种断句模式

- **智能断句**：遵循 `wjs-translating-subtitles` Skill，允许按标点合并或拆分字幕，适合直接观看。
- **严格时间轴**：保持原字幕条目数量和时间轴完全不变，适合已经进入剪辑工程的字幕。

## 数据和账户

- 视频文件不会上传，程序只读取用户选择的字幕文本。
- Codex CLI 使用当前电脑现有的 Codex 登录状态，程序不读取或保存认证文件。
- 每次翻译使用只读沙箱和结构化输出，Codex 不负责写文件；程序验证结果后再提供下载。
- 每次任务使用临时目录，返回结果后自动删除临时文件。
- 长字幕会消耗更多 Codex 用量，也需要更长处理时间。

## 开发命令

```powershell
npm test
npm start
```

程序只使用 Node.js 内置模块，没有第三方 npm 依赖。

默认明确调用 `gpt-5.6-sol`，推理强度为 `high`。也可以在启动前通过环境变量切换：

```powershell
$env:CODEX_MODEL = "模型名称"
$env:CODEX_REASONING_EFFORT = "high"
npm start
```
